## 🎯 What Can You Do With This Tool?

### Browse Certificates

The main window shows a list of all certificate stores on your computer. Click on any store (like "Personal" or "Trusted Root Certification Authorities") to see the certificates inside it.

### View Certificate Details

Select any certificate to see its details, including:

- Who issued the certificate
- Who it was issued to
- When it becomes valid
- When it expires
- The certificate's unique thumbprint

### Export Certificates

You can export any certificate to a file using one of three formats:

- **DER (.cer)** — A raw binary format, great for importing into other systems
- **PEM (.pem)** — A text-based format, commonly used on Linux and web servers
- **PKCS#12 (.pfx)** — A password-protected format that includes the private key, useful for backups

To export a certificate, simply select it and click the **Export** button. Choose your desired format and location, and the tool will create the file for you.
